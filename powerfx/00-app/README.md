# 00-app/

Formules au niveau de l'application (propriété `App`), pas d'un écran en particulier :
variable de langue, table de traductions.

- `OnStart.fx.txt` : à coller dans la propriété **App.OnStart** (Power Apps Studio > sélectionner
  **App** dans le menu déroulant en haut à gauche > propriété **OnStart**).

Voir [../README.md](../README.md) pour la note sur les séparateurs Power Fx en locale française.
