# scripts/

🚧 **À venir — Phase 1 et suivantes.**

Contiendra les scripts PowerShell du projet :

- authentification (`pac auth create`) ;
- création du schéma Dataverse (tables, colonnes, colonne formule d'échéance) ;
- export / dépaquetage / import de la solution (`pac solution export|unpack|import`) ;
- génération des données de démo fictives.

Aucun script de ce dossier ne doit contenir de secret, d'identifiant de locataire ni de courriel réel — voir `.gitignore`.
